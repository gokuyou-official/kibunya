# ルール反映後 実機確認手順書 (iPhone)

対象: TestFlight の KIBUNYA (v1.0.4 / Build 85)
目的: 2026-08-09 に反映した Firestore セキュリティルールで、既存機能が
壊れていないことを確認する。

## 事前準備

- 確認は iPhone 実機で行う (シミュレータ不可)。
- **★ が付いた項目は Kさん (kanemari0605@gmail.com) の協力が必要**。
  2 アカウント間の動作なので 1 台では確認できない。
- 各項目で「異常」だった場合は、**その場で止めて報告**すること。
  先に進むと原因の切り分けができなくなる。
- 異常時に報告してほしいこと (全項目共通):
  - どの項目の、どの操作で起きたか
  - 画面に出たメッセージの全文 (スクリーンショットが最良)
  - その時オンラインだったか (機内モードでないか)

---

## 1. ログイン

**やること**
アプリを起動し、既存アカウントでログインする。一度サインアウトしてから
ログインし直す。

**正常とみなす条件**
- ホーム画面まで到達する
- 自分の名前が正しく表示されている

**異常時に報告してほしいこと**
- ログイン後に画面が真っ白 / 名前が空欄 / 「フレンド」とだけ表示される
- エラーダイアログの全文

---

## 2. フレンド一覧

**やること**
フレンドタブを開く。一覧をしばらく (5秒ほど) 眺める。

**正常とみなす条件**
- 登録済みのフレンドが全員表示される
- 名前が空欄になっていない
- オンライン表示が付く人と付かない人がいる (全員オフラインでも可)

**異常時に報告してほしいこと**
- 一覧が空になった / 人数が減った
- 名前が空欄、または全員「フレンド」表示になっている
- いつまでも読み込み中のまま

---

## 3. フレンドの通知トグル (active)

**やること**
フレンド一覧で、誰か 1 人の通知トグルを OFF にする。
アプリを一度終了して再起動し、トグルの状態を確認する。
確認後、元に戻す。

**正常とみなす条件**
- OFF にした状態が再起動後も保持されている
- 元に戻す操作もエラーなく通る

**異常時に報告してほしいこと**
- トグルを操作した瞬間にエラーが出る
- 再起動したら勝手に ON に戻っている

---

## 4. 招待リンク ★【重点項目】

今回のルール変更が最も影響する箇所。**4-a から順に、飛ばさずに実施すること。**

### 4-a. 新規の相互登録 ★

**やること**
Kさんに招待リンクを送ってもらい、それを踏む
(またはこちらのリンクを Kさんに踏んでもらう)。
まだ友達になっていない組み合わせで行うこと。

**正常とみなす条件**
- 「友達になりました」のダイアログが出る
- **両方の端末**でフレンド一覧に相手が現れる (片方だけならこれは異常)

**異常時に報告してほしいこと**
- 「招待リンクの処理に失敗しました」が出た
- 片側にしか相手が現れない → **どちら側に現れなかったか**を明記

### 4-b. 同じリンクをもう一度踏む ★

**やること**
4-a で使ったリンクを、もう一度踏む。

**正常とみなす条件**
- 「友達になりました」が再度出る (エラーにならない)
- 一覧が壊れない (重複表示されない)

**異常時に報告してほしいこと**
- 「招待リンクの処理に失敗しました」が出た

### 4-c. 通知トグル OFF の相手のリンクを踏み直す ★

**この項目だけは「失敗が想定内」**。結果をそのまま報告してほしい。

**やること**
1. Kさんに、こちら (自分) の通知トグルを OFF にしてもらう
2. その状態で、こちらから Kさんの招待リンクをもう一度踏む

**想定される結果**
- 「招待リンクの処理に失敗しました」が出る可能性が高い
- これは Build 85 に修正が入っていないため。**バグではあるが既知**で、
  次のビルドで直る。ルール反映前は、この操作が成功する代わりに
  Kさん側のトグル OFF を黙って解除していた

**報告してほしいこと**
- 成功したか、失敗したか (どちらでも良いので事実をそのまま)
- 失敗した場合、**その後 Kさん側のトグルが OFF のままか**
  (OFF が保たれていれば、意図通りに守られている)

---

## 5. 気分の送信 ★

**やること**
ホームから気分を選んで送信する。

**正常とみなす条件**
- 送信が完了し、待機状態 (「待ちますかー」) になる
- エラーダイアログが出ない
- **Kさん側**に通知カードが届く

**異常時に報告してほしいこと**
- 送信時にエラーが出た
- 送信できたのに Kさん側に届かない
- 送信できたのに自分の画面が待機状態にならない

---

## 6. 受信と「かー」 ★

**やること**
Kさんから気分を送ってもらい、届いた通知カードで「かー」を押す。

**正常とみなす条件**
- 通知カードが表示される
- 「かー」を押すと 済👌 バッジが付く
- カードの本文は「かー」の前後で変化しない
- **Kさん側**にマッチのオーバーレイが出て、待機状態が自動で解除される

**異常時に報告してほしいこと**
- 「かー」を押してもバッジが付かない / エラーが出る
- カードの本文が「かー」の後で変わった
- Kさん側でオーバーレイが出ない、または待機状態が解除されない

---

## 7. アカウント削除

**★ この項目は最後に実施し、実施前に必ず一報を入れること。**
削除は取り消せない。捨てアカウントを用意できる場合はそちらで行うのが望ましい。

**やること**
設定からアカウント削除を実行する。

**正常とみなす条件**
- 削除が完了し、ログイン画面に戻る
- **Kさん側**のフレンド一覧から自分が消える

**異常時に報告してほしいこと**
- 削除の途中でエラーが出た (この場合データが中途半端に残っている
  可能性があるので、**必ず報告**すること)
- 削除できたのに Kさん側の一覧に自分が残り続ける

---

## 確認結果の報告フォーマット

全項目を通したら、以下の形で結果をまとめて報告してほしい。

```
1 ログイン            : OK / NG
2 フレンド一覧        : OK / NG
3 通知トグル          : OK / NG
4-a 招待リンク 新規   : OK / NG
4-b 招待リンク 再度   : OK / NG
4-c 招待リンク OFF後  : 成功 / 失敗 (失敗時: トグルは OFF のままか?)
5 気分の送信          : OK / NG
6 受信と「かー」      : OK / NG
7 アカウント削除      : OK / NG / 未実施
```
